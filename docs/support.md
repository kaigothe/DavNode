# Support

## Community support (free)

- Questions and ideas: GitHub Discussions.
- Bugs and client problems: GitHub Issues, using the templates.
- Security problems: private reporting, see [SECURITY.md](../SECURITY.md).

Answers come on a best-effort basis from the maintainer and other users.

## Help with setup and operation (on request)

For organisations that want a hand, the maintainer can take on, case by case:

- initial setup and hardening of a production deployment,
- migration from another CalDAV/CardDAV/WebDAV server,
- client rollout advice and troubleshooting,
- operations questions (backup, upgrades, sizing).

This is individual consulting, not a product: there are no price lists, no
service levels and no guaranteed response times yet. If you need those, say
so in your enquiry; they will be offered only when they can be kept.

**Contact:** open a GitHub Discussion titled "Support enquiry" (no secrets
in it) or write to the address on the maintainer's GitHub profile.

## Supporting the project

Sponsoring, contributing a client test report or a pull request all help.
Sponsorship options will be linked here once they are set up.
