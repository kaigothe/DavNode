# Directories and communities

Check each target's current rules before submitting; they change. Reuse the
text from [announcement.md](announcement.md), shortened.

| Target                                                                              | What                                                                                                   | Notes / rules to check                                                                                                                        |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted-data) | Pull request adding a YAML entry (category: Calendar & Contacts, Document management or File transfer) | Requires a release and documentation; read its contributing guide; the project must be maintained for a while and have a demo or install docs |
| [AlternativeTo](https://alternativeto.net/)                                         | New application entry, listed as alternative to Nextcloud, Radicale, Baïkal                            | Account required; neutral description                                                                                                         |
| [selfh.st](https://selfh.st/)                                                       | Newsletter/apps listing submission                                                                     | Check the submission form                                                                                                                     |
| Hacker News                                                                         | "Show HN" post of the repo or article                                                                  | Follow the Show HN guidelines; be present to answer                                                                                           |
| r/selfhosted                                                                        | Post with the article                                                                                  | Read the self-promotion and AI-disclosure rules first; flair as required                                                                      |
| Node Weekly / similar newsletters                                                   | Submit the article link                                                                                | Only if the Node.js angle is strong                                                                                                           |
| German-speaking forums (e.g. heise-Foren, Linux-/Selfhosting-Gruppen)               | German variant of the article                                                                          | Respect each forum's rules                                                                                                                    |
| GHCR / Docker Hub                                                                   | Package description and README                                                                         | Set after the first image publication                                                                                                         |

## Tracking

Per target, record in the issue tracker: date, link, number of replies,
bugs and requests that came out of it. Evaluate after four weeks:
image pulls, new issues (and how many were resolved), compatibility reports,
returning users. Stars are noted but not a goal.
