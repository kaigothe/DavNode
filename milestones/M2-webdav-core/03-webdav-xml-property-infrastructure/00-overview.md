# Große Aufgabe: WebDAV-XML- & Property-Infrastruktur

## Ziel
Wiederverwendbare Infrastruktur für alle XML-basierten WebDAV-Methoden
(PROPFIND/PROPPATCH jetzt, REPORT-Methoden in M3/M4/M5/M6 später): eine
XML-Parsing-/Multistatus-Serialisierungs-Schicht und eine
Property-Provider-Abstraktion, die Live- und Dead-Properties einheitlich
behandelt.
