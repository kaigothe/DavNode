# Große Aufgabe: Unternehmens-Readiness & Support-Modell

## Ziel
Firmen können eine Einsatzentscheidung treffen: klare Lizenzfolgen,
Sicherheitsangaben, Wartungsplan und eine Antwort auf „Wer unterstützt
den Betrieb?“. Realistisch klein starten: Community kostenlos, Einrichtung/
Support optional bezahlt.
