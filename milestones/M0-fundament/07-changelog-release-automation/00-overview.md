# Große Aufgabe: Changelog & Release-Automatisierung

## Ziel
Jeder Merge nach `main` wird automatisch anhand der Commit-Historie
(Conventional Commits) versioniert: `CHANGELOG.md` wird generiert, ein
Git-Tag gesetzt und eine GitHub-Release erstellt — ohne manuellen
Versionierungs-Schritt.
